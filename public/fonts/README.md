# Font provenance

The UI retains the same Geist and Geist Mono fonts as the initial Google Fonts stylesheet.
The exact WOFF2 resources observed in the baseline are served locally and preloaded to avoid a third-party stylesheet roundtrip and late font swaps.

- Geist: https://fonts.gstatic.com/s/geist/v5/gyByhwUxId8gMEwcGFWNOITd.woff2
- Geist Mono: https://fonts.gstatic.com/s/geistmono/v6/or3nQ6H-1_WfwkMZI_qYFrcdmhHkjko.woff2
- SIL Open Font License notices: included alongside each font, sourced from the Fontsource variable Geist/Geist Mono 5.3.0 distribution.

No financial or product branding changes are involved.
